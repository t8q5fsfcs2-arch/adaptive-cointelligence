## Invariants

This is the canonical **authored source home** for the future IKE-native Adaptive Cointelligence application. Start here when preparing its corpus. The Python demonstrator remains in place as a reference implementation. This directory does not register an app, create a Collection, or establish accepted Builder output.

Use the IKE application ownership and composition conventions of ADR-0029 §1–2 and §5–6; use ADR-0028 §6 for corpus preparation and the Builder. ADR-0026 §9–10 governs Ferb retrieval and Collection lifecycle. Resolve the current approved editions through the IKE platform owner. These references identify their authority; this repository does not copy or supersede the platform ADRs.

Keep confirmed human intent, app-owned domain meaning, observed product contracts, and generated runtime graphs distinct. Research, Design and Sponsor are example labels, not required roles. Project policy determines who may contribute, release, review, decide and see each record. No prototype default, index link or generated artifact grants authority.
