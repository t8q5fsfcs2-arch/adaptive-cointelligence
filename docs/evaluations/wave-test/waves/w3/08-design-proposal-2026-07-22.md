# Design proposal: one-tap reschedule
22 July 2026. Lee Chen (Design).

Research shows that patients who miss visits already know in advance and can't get through to reschedule. So the main path for all patients should be one-tap reschedule straight from the reminder message, with a visible "talk to staff" option.

Alternatives considered: portal login (too many steps), phone tree (doesn't fix after-hours).
